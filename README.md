# MySQL_Lego_Set_Data_Project
  This is a personal data analytics project created to sharpen my data analysis and data visualization skills using MySQL and ggplot2 in R. The project is an analysis of a data set that contains all Lego sets released from 1975 to 2025. The CSV can be found in the "datasets" folder. The folder "datascreening" contains the MySQL queries for screening the dataset before moving to the analysis. The "analysis" folder contains the MySQL queries for each analysis preformed. the beginning of each file name contains a letter followed by a number; each letter denotes whether it is a screening file, denoted "C", or a analysis file, denoted "A". The number acts as a unique identifier for each screening and analysis. The analysis "A1.5" is closely related to the analysis "A1", so therefore I denoted it "1.5" instead of "2".
